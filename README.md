# Pr-diction-du-risque-de-sant-mentale-chez-les-tudiants
Le projet vise à analyser un jeu de données afin de classifier et d’étudier les  facteurs associés au bien-être et au risque de santé mentale des étudiants. Le projet couvre toute la chaîne Data Science.  Le modèle ne doit jamais être présenté comme un outil de diagnostic, de décision disciplinaire ou de sélection d’étudiants.
